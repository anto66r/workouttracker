# Exercise illustrations

Drop an image file here named after the exercise type to use it instead of
the built-in hand-drawn sketch — no code changes needed.

Filename must match the exercise's internal type exactly:

```
bike, elliptical, rowing, running,
abs, back, biceps, calves, chest, forearms, glutes, hamstrings,
lats, quads, shoulders, triceps,
crunches,
plank
```

Supported extensions, tried in this order: `.png`, `.jpg`, `.jpeg`, `.webp`,
`.svg`. E.g. `running.png` or `plank.svg`.

Tips:
- Roughly square images work best (they're displayed in fixed-size boxes:
  ~52px in the form, ~22px in the history list).
- Transparent background recommended so it sits naturally on the app's dark
  surfaces.
- Any type without a matching file keeps using the built-in sketch, so you
  can add these gradually.
